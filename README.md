# StoryForge AI

StoryForge AI is a mobile interactive fiction game where players shape a story through their choices.

The player chooses a genre, makes decisions throughout the storyline, and at the end the app generates a personalised short novel based on their choices.

## Main Idea

The player does not just play a story — they create their own version of it.

Two players can play the same romance story but receive different final mini novels because their choices were different.

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- AsyncStorage
- Vercel Serverless Functions or Supabase Edge Functions
- OpenAI API
